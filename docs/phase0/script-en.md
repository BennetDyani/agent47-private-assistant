# Malume recording script: English

Record **one clip per line**. Name each clip with its code (e.g. `en01`). Speak naturally, the way you would talk to a real person.
If you say something different from the text, that's fine: just tell us what you actually said.

- **en01**: Hello Malume, how are you today?
- **en02**: Please read my new emails from this morning.
- **en03**: Remind me to call my mother at six this evening.
- **en04**: What is on my screen right now?
- **en05**: Send a message to Thabo saying I will be late.
